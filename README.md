# aina-portfolio

My personal portfolio site, built with **Next.js (App Router)** and **Tailwind CSS**, deployed on Vercel.

> Demo project for a fictional student persona (Sprout, Festival Idea Putrajaya 2026).

## Sections
- About me: final-year CS student, backend + AI
- Projects: cards that link to my GitHub repos
- Contact: email link

## Run it

```bash
npm install
npm run dev
```
